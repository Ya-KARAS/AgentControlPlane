# 油猴本地派发设计

状态：桌面本机候选审核、可选自动派发、网页适配器注册表和安全状态回传均已实现。
手机、中转、远程访问和网页内容提取仍不在范围内。

## 目标

让用户在已支持的桌面网页 AI 中准备一个小型任务候选，并交给本机
AgentControlPlane 审核。本机 ACP 持有派发决定权；网页和油猴脚本只能提交手动候选。

## 范围

本阶段只支持桌面浏览器与本机运行的 ACP。不包含手机、中转站、远程访问、网页对话提取
或自动选择执行器。

## 信任边界

网页内容默认不可信，包括 AI 回复、页面脚本、浏览器 DOM，以及任何看起来像 ACP 指令的
文字。油猴脚本不能把网页内容当成创建、延续、取消或批准工程任务的授权。

本机 ACP 的所有者才有权选择工作区、执行器、审核任务和执行工程工作。现有的工作区
白名单、仅回环绑定、速率限制、审计记录和执行器策略继续生效。

## 用户流程

1. 用户从油猴脚本打开 ACP 面板。
2. 面板默认为空，不读取或预填网页 AI 对话。
3. 用户手动填写精简目标和可选约束。
4. 面板把内容标记为“待本机审核的任务候选”。
5. ACP 打开本机审核页；如果所有者已在本机设置中开启自动派发，ACP 会使用保存的选择。
6. 工作区、执行器和 Profile 始终由本机所有者控制。自动派发默认关闭，只适用于油猴面板
   手动提交的候选。普通网页请求只能创建待审核候选。
7. 返回油猴脚本的结果只包含任务状态和数量。响应不包含原始本地日志、凭据、路径、执行器
   总结或错误原文。

## 必须遵守的安全规则

- 页面加载、页面跳转、DOM 变化或 AI 生成文本都不能自动创建、延续、取消任务或选择模型。
- 不自动读取、复制或传输聊天内容、Cookie、浏览器存储、本地路径、凭据、API Key 或 Token。
- 油猴脚本不持有长期 ACP 凭据。状态能力令牌绑定候选来源，一小时后过期，只保存在内存中。
- 本机审核界面必须拒绝过期、重复或未批准的任务候选。
- 油猴脚本不能绕过现有 ACP 的来源、鉴权、工作区、速率限制、审计和执行器策略检查。
- 初始版本只允许本机回环连接，不对公网暴露 ACP，也不充当中转站。
- 自动派发专用请求标记不在网页 CORS 允许头列表中。本机设置是最终策略门槛。

## 数据契约

候选数据有意小于 ACP 的工程简报：

```json
{
  "objective": "由用户输入的字符串",
  "constraints": ["可选的用户输入字符串"],
  "source": "userscript-preview"
}
```

候选数据不包含工作区路径、执行器标识、模型、凭据、对话记录、浏览器标识或本地文件数据。
所有本地执行选择都由 ACP 在审核步骤中解析。

## 模块边界

- `src/core/candidate-review.js` 负责与传输无关的候选状态机、过期、一次性批准、
  重放拒绝和派发回调。
- `src/local-review/service.js` 把本机 ACP 的工作区、执行器、配置、审计和编排策略
  适配到核心服务。
- `src/local-review/router.js` 只负责回环 HTTP、来源处理、有限请求体解析和响应状态映射。
- `src/local-review/page.js` 渲染不含脚本的本机确认页面。
- `src/local-review/settings.js` 负责本机默认选择、自动派发开关、持久化和一次性设置表单保护。
- `userscript/src/adapters/` 中每个站点都是独立的数据模块，公共注册表负责校验和解析。
- `userscript/` 是客户端层，不能导入服务器、编排器、执行器、工作区或 MCP 模块。

候选核心服务不依赖 HTTP、浏览器 API、MCP、执行器实现或网页适配器。未来客户端必须复用
服务契约，不能在自己的传输层里增加派发逻辑。

部分 Chromium 扩展流程会在提交顶层本机确认表单时发送不透明来源 `Origin: null`。
ACP 只在回环审核路由接受该值，一次性确认令牌和本机选择校验仍为必需条件。候选创建
仍要求网页来源位于允许列表。

## 实现门槛

只有持续满足以下测试条件，该实现才可接受：

1. 在加入本机审核能力前，油猴静态测试证明不存在聊天提取、网络动作或任务变更。
2. 本机审核集成测试证明，默认状态下没有明确且新鲜的本机确认，候选不能产生任务。
3. 反向测试证明页面提供的任务形状文字、重复请求、过期候选、未知来源和工作区覆盖都会被拒绝。
4. 安全审查确认现有 ACP 的回环、鉴权、工作区、审计和速率限制不变量仍然成立。
5. 任何超出本机审核边界的安全敏感扩展，都必须在实现前单独审查。
6. 状态测试证明能力令牌与候选来源绑定，网页投影会排除目标、路径、总结、日志和错误原文。
7. 自动派发测试证明其默认关闭、设置表单令牌只能使用一次、本机选择必须通过允许列表，
   普通网页 CORS 请求不能触发自动派发。

## 明确不做的内容

本文不规定设备配对、手机流程、中转协议、加密实现、托管、定价、遥测或多用户访问。
桌面本机审核流程通过安全门槛后，这些领域再分别设计。
